# 小蛋蛋闯关

送给喜欢蛋仔派对的小朋友：在自己的电脑上，用浏览器玩的三关跳跃游戏。粉色小蛋蛋要跳过小沟、踩着白云、躲开慢慢转的糖果，去捡星星、碰到终点的旗子。

没有登录，没有广告，也不用联网。掉下去会回到刚才站稳的地方，可以一直试。

## 在家里打开

电脑上需要有 Python（Mac 和大多数 Linux 已经自带）。不需要再安装别的东西。

1. 打开终端，进入这个游戏所在的文件夹（里面能看到 `index.html`）。
2. 运行下面这一条命令：

```bash
python3 -m http.server
```

3. 终端里会印出地址，一般是 `http://127.0.0.1:8000` 。用浏览器打开它。

玩完后，回到终端按 `Ctrl + C` 就可以关掉。

## 怎么操作

- 键盘：方向键或 `W` `A` `S` `D` 移动，空格或上方向键跳跃。
- 屏幕：点下面的大按钮「左」「右」「跳」。鼠标和触摸都可以，手机横过来更好玩。
- 走到旗子那里就过关。路上的星星可以顺手捡。
- 右上角「声音」可以关掉音效。音效要先点一下或按一下键才会响，这是浏览器的规矩。

## 三关

1. 星星小路：平平的路、小沟沟，还有一个弹跳垫。
2. 软软云朵：会动的云，站上去就能过宽一点的空隙。
3. 旋转糖果：等糖果转开再过去，然后跳上几级台阶。

三关都玩完，小蛋蛋会跳舞。点「再玩一次」可以从头再来。
